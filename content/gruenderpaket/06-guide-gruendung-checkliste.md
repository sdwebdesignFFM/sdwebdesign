```
Wenn Sie gerade gründen, stehen Sie vor einer Welle an Einzelentscheidungen — Domain, E-Mail, Logo, Rechtstexte, Buchhaltung, Website, Social Media, CRM, Cloud. Jede einzelne davon wirkt klein. Zusammen verschlingen sie in der Regel mehr Zeit als das eigentliche Gründen.

- Was wirklich Pflicht ist (und was nur nice-to-have)
- In welcher Reihenfolge Sie die Punkte angehen sollten
- Womit Sie mit einem Tag oder einem Nachmittag durchkommen
- Wo Sie besser einen Dienstleister einschalten

Diese Checkliste ist neutral geschrieben. Wenn Sie sie lieber komplett delegieren wollen, liefern wir das alles als [Gründerpaket Frankfurt](/loesungen/gruenderpaket-frankfurt) aus einer Hand.
```

**Inhalt** (HTML / Rich-Text):

```
<p>Drei Entscheidungen müssen vor jeder digitalen Einrichtung getroffen sein, weil alles andere daran hängt:</p>

<p><strong>1. Ihre Gründungsform.</strong> Einzelunternehmen oder Freiberufler? UG oder GmbH? Diese Entscheidung beeinflusst, welche Rechtstexte Sie brauchen, wie die Rechnungen aussehen müssen und welche Rechtsform im Impressum steht. <p><strong>3. Ohne diesen Satz schreiben Sie im nächsten Schritt nur Floskeln auf die Website.</p>

<p><em>Zeitaufwand Schritt 0: 1–2 Tage, verteilt über 1–2 Wochen, weil Steuerberater- und Marken-Rückmeldungen dauern.</em></p>
```

#### Section 2 — Domain & Business-E-Mail

**Überschrift**:
```
1. Domain & Business-E-Mail (Pflicht)
```

**Inhalt**:
```
<p><strong>Was Sie brauchen:</strong> Eine eigene Domain (<code>ihrname.de</code>) und professionelle E-Mail-Adressen auf dieser Domain (<code>info@ihrname.de</code>, <code>name@ihrname.de</code>). Gmail-Adressen auf der Visitenkarte wirken wie Hobby-Projekt.</p>

<p><strong>Kostenrahmen:</strong> 10–30 € pro Jahr für eine .de-Domain. 3–8 € pro Monat für ein professionelles E-Mail-Postfach bei einem deutschen Provider.</p>

<p><strong>Empfehlung:</strong> Domain und E-Mail beim selben deutschen Provider registrieren (mailbox.org, Strato, IONOS Cloud, Hetzner). Gründe: DSGVO-Konformität, ein einziger Ansprechpartner, SPF/DKIM/DMARC werden automatisch korrekt gesetzt.</p>

<p><strong>Worauf Sie achten müssen:</strong></p>
<ul>
<li>Der Registrar muss DNSSEC unterstützen</li>
<li>Der E-Mail-Provider muss SPF, DKIM und DMARC korrekt konfigurieren — sonst landen Ihre E-Mails im Spam-Ordner Ihrer Kunden</li>
<li>Vermeiden Sie kostenlose E-Mail-Angebote bei unbekannten Providern — Domain-Hijacking ist real</li>
</ul>

<p><em>Zeitaufwand: 2–3 Stunden für die Einrichtung.</em></p>
```

#### Section 3 — Corporate Identity & Logo

**Überschrift**:
```
2. Corporate Identity & Logo (Pflicht, wenn Sie professionell wirken wollen)
```

**Inhalt**:
```
<p><strong>Was Sie brauchen:</strong> Ein Logo (Wortmarke oder Wort-Bild-Marke), eine Farbpalette (Primär-, Sekundär-, Neutraltöne), eine Typografie-Kombination (eine Haupt- und eine Body-Schrift), ein minimales Style-Mini-Manual als PDF.</p>

<p><strong>Kostenrahmen:</strong></p>
<ul>
<li>Fiverr / 99designs: 50–500 € — Ergebnis meist Template-basiert, selten individuell.</li>
<li>Freelancer / Grafiker: 800–2.500 € für ein ordentliches Logo, oft ohne Manual.</li>
<li>Agentur / Paket: 2.000–5.000 € für komplettes Markensystem mit Manual.</li>
<li>Volles Corporate-Design-Projekt: 10.000–50.000 € (für Gründer overkill).</li>
</ul>

<p><strong>Empfehlung:</strong> Gehen Sie nicht unter 800 €, aber zahlen Sie auch nicht 10.000 €. Der Sweet Spot für Gründer liegt bei einem Paket, das Logo, Farben, Typografie und ein Mini-Manual als PDF enthält. Mehr dazu in unserer Leistung <a href="/loesungen/logo-corporate-identity-gruender">Logo & Corporate Identity für Gründer</a>.</p>

<p><strong>Warum das Manual wichtig ist:</strong> Sobald Sie einen Flyer drucken lassen, eine Visitenkarte gestalten oder eine Messe-Grafik brauchen, muss jemand wissen, welche Farbe, welche Schrift, welche Logo-Variante korrekt ist. Ohne Manual bauen Sie jedes Mal neu — und jedes Mal ein bisschen anders.</p>

<p><em>Zeitaufwand: 2 Wochen für ein solides Paket, wenn Sie jemanden beauftragen.</em></p>
```

#### Section 4 — Website

**Überschrift**:
```
3. Website (Pflicht für die meisten Gründer)
```

**Inhalt**:
```
<p><strong>Was Sie brauchen:</strong> Eine Website mit mindestens Startseite, Über uns, Leistungen, Kontakt, Impressum, Datenschutz. Responsive, schnell, rechtssicher.</p>

<p><strong>Kostenrahmen:</strong></p>
<ul>
<li>Baukasten (Jimdo, Wix, IONOS): 10–40 € pro Monat, Selbstbau.</li>
<li>Freelancer: 1.500–4.000 € für einmalige Erstellung, meist ohne Rechtstexte und SEO-Basis.</li>
<li>Agentur-Paket: 2.500–6.000 € für eine professionelle, rechtssichere Gründer-Website.</li>
<li>Individuelle Website mit Funktionen: 5.000–15.000 €.</li>
</ul>

<p><strong>Was oft vergessen wird:</strong></p>
<ul>
<li>Cookie-Banner mit Consent-Management (Pflicht seit 2020)</li>
<li>Impressum, das zur Gründungsform passt (Einzelunternehmer vs. UG unterschiedlich)</li>
<li>Datenschutzerklärung, die mit den eingesetzten Tools konsistent ist (Google Analytics braucht anderen Text als Matomo)</li>
<li>SSL-Zertifikat — heute Standard, ist aber bei Billig-Hostern manchmal zusätzliche Kosten</li>
</ul>

<p><strong>Empfehlung:</strong> Nicht unter 1.500 €, nicht über 6.000 € — außer Sie haben besondere Anforderungen. Mehr dazu in unserem Ratgeber <a href="/ratgeber/website-kosten-existenzgruender">Was kostet eine Website für Existenzgründer?</a> und unserer Leistung <a href="/loesungen/website-fuer-existenzgruender">Website für Existenzgründer</a>.</p>

<p><em>Zeitaufwand: 4–8 Wochen bei einem Dienstleister, 1–3 Monate bei Eigenbau (inklusive Content-Pflege).</em></p>
```

#### Section 5 — Rechtstexte & Compliance

**Überschrift**:
```
4. Rechtstexte & Compliance (Pflicht — keine Option)
```

**Inhalt**:
```
<p><strong>Was Sie brauchen:</strong></p>
<ul>
<li><strong>Impressum</strong> — nach §5 TMG und §18 MStV, inhaltlich abhängig von Ihrer Gründungsform</li>
<li><strong>Datenschutzerklärung</strong> — nach Art. 13 DSGVO, mit Auflistung aller Datenverarbeitungen</li>
<li><strong>Cookie-Banner</strong> mit granularer Einwilligung (Consent-Management-Platform)</li>
<li><strong>Widerrufsbelehrung</strong> — nur wenn Sie online Verträge mit Verbrauchern schließen</li>
<li><strong>AGB</strong> — empfohlen, nicht immer Pflicht</li>
</ul>

<p><strong>Kostenrahmen:</strong></p>
<ul>
<li>Generator (eRecht24, e-recht24, Datenschutz.de): 0–15 € pro Monat. Rechtssicher auf Basis-Niveau, nicht zugeschnitten.</li>
<li>Fachanwalt: 500–2.500 € für eine saubere, individuelle Erstellung.</li>
<li>Agentur-Paket (inkl. Einbindung): im Gründerpaket enthalten.</li>
</ul>

<p><strong>Was oft schief geht:</strong> Generator-Texte sind rechtlich im Groben okay — aber sie hinken hinter aktuellen Urteilen hinterher (z.B. TTDSG 2021, Consent-Urteile 2023, KI-Richtlinien 2025). Abmahnfähig werden sie oft, wenn Sie neue Tools einsetzen (z.B. ein neues Tracking-Tool), ohne die Datenschutzerklärung zu aktualisieren.</p>

<p><strong>Empfehlung:</strong> Wenn Sie sensible Daten verarbeiten (Gesundheit, Recht, Finanzen, Kinder), gehen Sie direkt zum Fachanwalt. Für alle anderen reichen gute Generator-Texte, sofern sie gepflegt werden.</p>

<p>Mehr dazu im Detail in unserem <a href="/ratgeber/impressum-pflicht-selbststaendige">Impressum-Pflicht-Ratgeber</a>.</p>

<p><em>Zeitaufwand: 2–4 Stunden für Generator-Lösung, 1–2 Wochen für Fachanwalts-Lösung.</em></p>
```

#### Section 6 — Buchhaltung & Rechnungen

**Überschrift**:
```
5. Buchhaltung & Rechnungsstellung (Pflicht)
```

**Inhalt**:
```
<p><strong>Was Sie brauchen:</strong> Ein Rechnungs-Tool, das GoBD-konform und DATEV-kompatibel ist. Alles, was handschriftlich in Excel läuft, bereitet Ihrem Steuerberater spätestens beim ersten Jahresabschluss Kopfschmerzen.</p>

<p><strong>Empfehlungen (Gründer-tauglich):</strong></p>
<ul>
<li><strong>sevDesk</strong> — solider Marktstandard, ca. 16–30 € pro Monat</li>
<li><strong>lexoffice</strong> — ähnlich, ca. 10–30 € pro Monat</li>
<li><strong>Papierkram</strong> — günstiger (ab 8 €/Monat), schlanker Funktionsumfang</li>
<li><strong>lexware office</strong> — für etwas komplexere Fälle</li>
</ul>

<p><strong>Was integriert werden sollte:</strong></p>
<ul>
<li>Ihr Geschäftskonto (automatisches Matching von Zahlungseingang zu Rechnung)</li>
<li>Ein zentrales Kontaktverzeichnis (damit Sie nicht in jedem Tool Kontakte neu anlegen)</li>
<li>DATEV-Export für Ihren Steuerberater</li>
</ul>

<p><strong>Pflicht-Merkmale jeder Rechnung (2026):</strong> Name + Adresse beider Parteien, Steuernummer oder USt-ID, fortlaufende Rechnungsnummer, Leistungsdatum, Ausstellungsdatum, Bezeichnung der Leistung, Nettobetrag + Mehrwertsteuer (oder „Kleinunternehmer nach §19 UStG"). Ab 2025 kommt zusätzlich die E-Rechnungs-Pflicht im B2B-Bereich — Ihr Tool muss das können.</p>

<p><em>Zeitaufwand: 1 Nachmittag für die Einrichtung.</em></p>
```

#### Section 7 — Google Business Profile & lokale Sichtbarkeit

**Überschrift**:
```
6. Google Business Profile & lokale Sichtbarkeit (Pflicht für lokale Gründer)
```

**Inhalt**:
```
<p><strong>Was Sie brauchen:</strong> Ein vollständig ausgefülltes Google Business Profile — wenn Sie Kunden in Frankfurt und dem Rhein-Main-Gebiet gewinnen wollen, ist das nicht optional.</p>

<p><strong>Kostenrahmen:</strong> Kostenlos.</p>

<p><strong>Was reinkommt:</strong></p>
<ul>
<li>Korrekte Adresse (exakt gleich wie auf der Website und im Impressum)</li>
<li>Primär-Kategorie (z.B. „Webdesign-Unternehmen", „Physiotherapie-Praxis", „Rechtsanwalt") und zwei bis vier Sekundär-Kategorien</li>
<li>Öffnungszeiten (konsistent mit der Kontaktseite)</li>
<li>Beschreibung (750 Zeichen) mit Ihren Ziel-Keywords</li>
<li>Leistungen (jede als separater Eintrag)</li>
<li>Mindestens 10 Fotos: Team, Büro/Praxis, Arbeit in Aktion, Logo</li>
<li>Verifizierung (meist per Postkarte, manchmal per Video)</li>
</ul>

<p><strong>Bewertungs-Strategie:</strong> Fragen Sie Ihre ersten zehn Kunden direkt nach einer Google-Bewertung — mit einem Direkt-Link, damit sie nicht erst suchen müssen. Fünf bis zehn Bewertungen sind die Schwelle, ab der Sterne im Local Pack angezeigt werden.</p>

<p><strong>Häufigster Fehler:</strong> Falsche Kategorie („Unternehmen" oder „Dienstleistung" statt der spezifischen Kategorie). Das ist laut Whitespark-Analysen der #1 negative Ranking-Faktor im Local Pack.</p>

<p><em>Zeitaufwand: 2–3 Stunden initial, plus Verifizierungs-Wartezeit (bis zu 14 Tage per Postkarte).</em></p>
```

#### Section 9 — Cloud, Kollaboration & Passwort-Management

**Überschrift**:
```
8. Cloud, Kollaboration & Passwort-Management (oft übersehen)
```

**Inhalt**:
```
<p><strong>Was Sie brauchen:</strong></p>
<ul>
<li>Ein Cloud-Speicher für Dokumente, Verträge, Angebote (Nextcloud, Google Workspace, Microsoft 365 — jeweils DSGVO-konform konfiguriert)</li>
<li>Einen Kalender (meist im Cloud-Paket enthalten)</li>
<li>Einen Passwort-Manager (1Password, Bitwarden) — damit Sie Domain-, E-Mail-, Bank-, Tool-Zugänge nicht in einer Textdatei auf dem Desktop haben</li>
</ul>

<p><strong>Kostenrahmen:</strong></p>
<ul>
<li>Nextcloud (selbst gehostet oder bei deutschen Anbietern wie ownCube, Nextcloud-Anbietern): 3–10 €/Monat</li>
<li>Google Workspace Business Starter: ca. 6 €/Monat + AVV</li>
<li>Microsoft 365 Business Basic: ca. 6 €/Monat + AVV</li>
<li>1Password Business: ca. 8 €/Monat, Bitwarden kostenlos bis 2 Nutzer</li>
</ul>

<p><strong>Warum wichtig:</strong> Spätestens beim ersten Mitarbeiter oder Freelancer brauchen Sie ein geteiltes Ablage-System, einen Team-Kalender und einen kontrollierten Zugang zu Passwörtern. Ohne Struktur wird das schnell ein Sicherheits-Albtraum.</p>

<p><em>Zeitaufwand: 1 Nachmittag für Initial-Setup, monatliche Pflege.</em></p>
```

#### Section 10 — CRM (leichtgewichtig)

**Überschrift**:
```
9. CRM / Kontakt-Management (empfohlen)
```

**Inhalt**:
```
<p><strong>Was Sie brauchen:</strong> Ein Tool, das alle Anfragen, Kontakte, Angebote zentral speichert. Ohne CRM laufen Ihre Kontakte in Excel, dem E-Mail-Postfach, dem Handy und einem Notizblock parallel — nach drei Monaten wissen Sie nicht mehr, wer an welchem Angebot dran ist.</p>

<p><strong>Gründer-taugliche Optionen:</strong></p>
<ul>
<li><strong>HubSpot Free</strong> — kostenlos, solide Basis</li>
<li><strong>Pipedrive Starter</strong> — ca. 14 €/Monat, gut für Vertrieb</li>
<li><strong>Folk</strong> — ca. 15 €/Monat, für Gründer mit Beziehungs-Fokus</li>
<li><strong>Airtable</strong> — flexibel, ab 10 €/Monat, für Gründer, die es selbst bauen wollen</li>
</ul>

<p><strong>Empfehlung:</strong> Starten Sie mit HubSpot Free — kostenlos, gut strukturiert, wächst mit. Wenn Sie später ein dediziertes Vertriebstool wollen, ist ein Wechsel zu Pipedrive oder Salesforce einfach.</p>

<p><em>Zeitaufwand: 2–3 Stunden Initial-Setup.</em></p>
```

#### Section 11 — Zusammenfassung & Budget-Rechnung

**Überschrift**:
```
Budget-Übersicht: Was kostet das komplette digitale Setup?
```

**Inhalt**:
```
<p><strong>Wenn Sie alles selbst machen:</strong> 10–30 € Domain + 3–8 €/Monat E-Mail + ~50 € Logo (Fiverr) + 0–40 €/Monat Website (Baukasten) + 0–15 €/Monat Rechtstexte-Generator + 10–30 €/Monat Buchhaltung + 0 € Google Business Profile + 6 €/Monat Cloud + 0–8 €/Monat Passwort-Manager + 0 € CRM = <strong>~100–200 € einmalig + ~40–100 €/Monat laufend</strong>. Zeitaufwand: 4–8 Wochen, oft mehr.</p>

<p><strong>Wenn Sie ein Agentur-Paket kaufen:</strong> 2.500–6.000 € einmalig (Website + Logo + Rechtstexte + GBP-Setup + Social + Einweisung) + ~40–80 €/Monat laufend (Domain, E-Mail, Buchhaltung, Cloud). Zeitaufwand: 4–6 Wochen, davon 5–10 Stunden Ihre eigene Zeit.</p>

<p><strong>Was Sie beim Paket kaufen, ist nicht nur das Ergebnis, sondern die Zeit.</strong> Wenn Sie rechnerisch auf einen Stundensatz von 50 € kommen, brechen die meisten DIY-Ansätze spätestens nach 40–60 Stunden in die Region, in der ein Agentur-Paket günstiger ist — und Sie haben trotzdem noch keinen Steuerberater-tauglichen Workflow.</p>

<p>Falls das Paket-Modell für Sie passt: <a href="/loesungen/gruenderpaket-frankfurt">Das Gründerpaket Frankfurt im Detail</a>.</p>
```
